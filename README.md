# DAct

Конвертер файлов в трее. Исходный файл не перезаписывается: готовая копия ложится рядом, а если имя уже занято — с номером в скобках, `shot (1).jpg` и дальше.

На Windows жест такой. Выделяешь файл в проводнике или начинаешь его тащить, зажимаешь Alt и левую кнопку мыши. Под курсором открывается круг. Кнопку не отпускаешь, наводишься на сектор и только тогда отпускаешь. Повторное нажатие Alt переключает кольцо конвертации и кольцо инструментов. В настройках Alt можно сменить на Shift или Ctrl.

Окно можно закрыть, процесс от этого не завершается. Выход — пункт Quit в меню иконки.

Файлы одного типа можно кинуть пачкой в окно программы или передать в командной строке. Смешивать нельзя: jpg и mp4 в одном заходе она не возьмёт.

## Форматы

Картинки png, jpg, webp, tiff, bmp, gif, ico конвертируются друг в друга и в pdf. Несколько картинок собираются в один pdf. Отдельно: сжатие, размер, поворот на 90°, снятие exif.

pdf уходит в txt. Ещё можно пережать перезаписью, разрезать по страницам, повернуть, склеить несколько pdf, вытащить встроенные картинки и убрать Info/Metadata.

txt, md, csv, log, json, xml, html — в pdf или docx. docx обратно в txt, по абзацам. Вёрстка, таблицы и картинки из документа при этом теряются, остаётся текст.

Звук и видео без ffmpeg не конвертируются. Аудио: mp3, wav, flac, m4a, aac, aiff, ogg, opus. Видео: mp4, mov, mkv, webm, avi, m4v. Из видео можно снять дорожку в mp3, aac или flac. heic, heif и avif своим декодером не открываются, им тоже нужен ffmpeg.

Видео перекодируется. Для webm это vp9, для остальных контейнеров x264. Звук в mkv копируется как есть, в остальных случаях пережимается.

## Куда сохраняет

По умолчанию в ту же папку, что и исходник. В настройках есть второй вариант: подпапка `DAct` рядом с файлом.

Качество jpeg по умолчанию 90. Для команды Compress открывается свой ползунок, стартовое значение 72.

Настройки: `%APPDATA%\DAct\settings.toml`.
Лог: `%LOCALAPPDATA%\DAct\log.txt`. После мегабайта текущий лог переименовывается в `log.old.txt`.

Галка автозапуска пишет в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` значение `DAct`: полный путь к exe и флаг `--quiet`.

## FFmpeg

Картинки, pdf и текст работают без него. При старте ничего не скачивается.

На Windows кнопка Get FFmpeg берёт essentials-сборку с [gyan.dev](https://www.gyan.dev/ffmpeg/builds/) и кладёт `ffmpeg.exe` и `ffprobe.exe` в `%LOCALAPPDATA%\DAct\ffmpeg`. Свой бинарник можно указать в настройках. Если поле пустое, программа ещё смотрит PATH и несколько обычных путей вроде `C:\ffmpeg\bin`.

Эта сборка gyan.dev под GPL: в ней libx264 и lame. В репозиторий она не входит, MIT на код DAct на неё не распространяется. Если будете класть этот ffmpeg внутрь установщика, его лицензию надо соблюдать отдельно.

На macOS и Linux кнопка скачивания не работает. ffmpeg ставится своим пакетным менеджером, путь прописывается в настройках.

Жест с выделением в проводнике тоже только Windows. Окно, в которое файлы перетаскивают, и команда `dact convert` от проводника не зависят. Под macOS и Linux код автозапуска есть (LaunchAgent и `autostart/dact.desktop`), но вся эта связка гонялась на Windows.

## Команды

```
dact
dact --quiet
dact C:\files\shot.png
dact convert C:\files\shot.png --to WEBP
dact --selftest
dact --version
```

`--quiet` поднимает трей и не показывает окно. Так же стартует автозапуск.

`convert` печатает путь к готовому файлу. `--to` один на все файлы в этой команде. Для звука и видео цель пишется так же: `dact convert clip.mkv --to MP4`.

`--selftest` делает png и txt во временной папке, гоняет jpeg/webp/bmp/pdf, resize, compress и печатает `SELFTEST OK`. Звук и видео в эту проверку не входят.

Если DAct уже запущен, второй процесс с файлами не открывает новое окно, а отдаёт их первому.

## Сборка

Нужен текущий stable Rust. На Windows ещё линкер MSVC: Build Tools или Visual Studio с рабочей нагрузкой C++.

```
cargo build --release
```

Бинарник лежит в `target\release\dact.exe`.

`cargo test` проверяет мелочи вроде расширений и уникальных имён файлов. Конвертацию картинки и текста смотрит `dact --selftest`.
